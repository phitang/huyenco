# Huyền Cơ

Ứng dụng xem Tử vi Đẩu Số, Thần số học Pythagoras và bói bài Tarot.

- **Tử vi**: lập lá số 12 cung, tổng quan cuộc đời, vận hạn từng năm, định hướng nghề nghiệp, xem hợp tuổi hôn nhân và cách hóa giải.
- **Thần số học**: số chủ đạo, sứ mệnh, linh hồn, nhân cách, biểu đồ ngày sinh, chu kỳ năm và tháng cá nhân.
- **Tarot**: bộ 78 lá, trải 1, 3 hoặc 5 lá, giải mã vận mệnh tương lai gần.
